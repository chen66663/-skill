# 本地 C 规范映射

来源：用户提供的 `C语言编码规范_实践课内容.txt（已更新，共13页）`。该文件标注为 13 页，正文标题覆盖第 1 页至第 13 页；以下是供技能执行的规则映射，不替代原文。

## 效力与本文件定位

本文件是 `SKILL.md` 的配套参考，不是独立的规则来源，也不覆盖 `SKILL.md`。冲突时的效力顺序是：用户项目规范、芯片勘误和安全要求 → `SKILL.md`「强制检查项」→ 本文件「外部共识条目」→ 本文件的课件映射（页面要点、章节索引）→ `references/` 其余文件的依据性说明。本文件内部冲突时以「外部共识条目」为准。门禁数值以「页面要点」表为唯一登记口径，规则正文见 `SKILL.md` 对应小节，同一规则不要在两侧重复描述。

## 页面要点

| 页面 | 执行要点 |
| --- | --- |
| 1 | 小写 snake_case 变量/函数、UpperCamelCase 类型、UPPER_SNAKE_CASE 宏/常量；4 空格；避免 Tab；控制结构使用花括号；行宽约 80-100。 |
| 2 | 禁止不安全输入；显式转换；正确使用 `const`；检查分配失败并释放；统一错误码。STM32 实时路径默认禁止动态分配。 |
| 3 | 普通对象/函数只在 `.c` 定义；头文件只声明；外部符号集中声明；避免多重定义，映射 MISRA-C 8.5/8.8。 |
| 4 | 头文件必须有 include guard；模块负责创建和拥有自己的队列，并提供清晰的初始化/发送/接收接口。 |
| 5 | 源文件先包含对应头文件，再按标准库、第三方/芯片库、项目头文件分组；头文件提供声明、typedef、宏，不放普通定义。 |
| 6 | 本地课件要求 `/* */` 注释；本项目所有 `.c`、`.h` 里的注释统一使用 GB2312 编码的简体中文，任何文件出现 UTF-8 中文注释都算缺陷、必须逐个转换。注释写意图和约束，不凑行数。 |
| 7 | `if/switch/for/while/do` 使用复合语句；循环最多一个用于退出的 `break`。 |
| 8-10 | 花括号消除悬挂 `else`；避免 `while` 中导致计数器不更新的 `continue`；`switch` 有 `default`；`if/else if` 结构以 `else` 收尾。 |
| 11 | 文件作用域 `static` 限制内部符号；`const` 保护只读对象；外部接口集中声明。 |
| 12 | 自动变量使用前初始化；指针判空；数组边界检查；禁止返回局部变量地址或保存到静态指针。 |
| 13 | 参考门禁：注释率不低于 25%、圈复杂度不超过 10、嵌套深度不超过 4、函数代码不超过 200 行、相似代码段不超过 25 行；门禁按工程整体统计，不对单文件设配额（`.h` 只保留关键接口的文档块）；附录提供 ISO-C90 最小限制值，实际以工程编译器为准。 |

## 与 STM32 的适配

- 课件中的通用 C 规则不能覆盖 ISR、DMA、寄存器、缓存一致性和总线错误；这些由入口技能中的 STM32 专项规则补充。
- 课件示例使用的 `malloc`、`errno`、`NULL` 等来自通用/主机 C；在裸机项目中改用项目已有的固定宽度类型、错误码和静态存储策略。
- “禁止 continue”是保守的 MISRA-C 2004 门禁策略；若工程允许例外，必须证明循环进展不受影响，并记录偏离理由。
- ISO-C90 最小限制值不是所有 STM32 工具链的语言上限。不要为满足旧限制而牺牲 `stdint.h`、`static inline` 或编译器明确支持且工程已采用的特性。
- 注释率、圈复杂度等门禁的数值统一登记在本文件「页面要点」表，规则正文见 `SKILL.md` 对应小节；本文件不再重述规则正文，避免两处维护后出现不一致。
